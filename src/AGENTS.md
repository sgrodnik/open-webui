# Инструкции для агента

Перед началом любой работы обязательно прочитай файл плана проекта: `../plan.md` (относительно каталога `src`). Следуй правилам и актуальным решениям, записанным в плане. В частности, не начинай реализацию, пока пользователь явно её не разрешил.

## Основной инстанс (проверено 2026-10-30)

- Запущен отдельным Docker-контейнером, не через Docker Compose.
- Текущий образ `open-webui-custom:v0.12.5` собран Buildx из корня репозитория, ветка `upgrade/v0.12.5-custom`: upstream-тег `v0.12.5` плюс локальные изменения панели недавних чатов и горячих клавиш.
- Дополнительных адресов (`ExtraHosts`) нет.
- Пользовательских переопределений переменных окружения нет.
